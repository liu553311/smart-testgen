User Login Feature Requirements

The system shall provide a user login page accessible at /login.

Functional Requirements:
1. Users can log in using registered email and password
2. The system validates credentials against the database
3. On successful login, redirect to the dashboard page (/dashboard)
4. On failed login, display error message "Invalid email or password"
5. Account locks after 5 consecutive failed attempts for 30 minutes
6. "Remember me" checkbox keeps the session active for 7 days
7. "Forgot password" link sends a reset email to the registered address
8. Password field must be masked (show dots instead of characters)
9. Email field accepts valid email format (e.g., user@example.com)
10. Both fields are required (display validation error if empty)

Security Requirements:
1. Passwords must be transmitted over HTTPS only
2. Login attempt rate limiting: max 10 attempts per minute per IP
3. Session tokens must expire after 24 hours of inactivity
4. XSS prevention on all input fields

Performance:
1. Login page loads within 2 seconds
2. Authentication response within 1 second
